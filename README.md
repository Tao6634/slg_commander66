## 能改什么

Agent17 的存档里一共有 **655 个变量**，其中 **508 个**是可以直接改的标量（数字 / 开关 / 文字）。界面按用途分成 7 个页签：

| 页签 | 内容 | 数量 |
|---|---|---|
| 金钱与数值 | 主货币 `g_gold`、监狱币、赌场筹码、各角色身上的钱、等级类数值 | 22 个常用变量 |
| 背包物品 | 每件物品的数量 | 47 项 |
| 角色数据 | 每个角色的好感上限、认识状态、HP、锁定 | 98 项 |
| 技能等级 | 烹饪、开锁、按摩等技能的等级和经验 | 9 项 |
| 相册解锁 | CG / 影片的解锁状态 | 16 项 |
| 按摩好感 | 各部位的好感度 | 3 项 |
| 卡片翻面 | 小游戏卡片的翻面状态 | 5 项 |
| 全部变量 | 搜索任意变量名，直接改 | 508 个 |

剩下的 147 个是「容器对象」（背包、任务表这类），其中常用的几种已经做成独立的页签了。

### 改法

1. 左上角选中要改的存档（默认选最近保存的那个）
2. 在任意页签里选中一项 → 填新值 → 点 **加入待修改**
3. 全部攒好之后，点底部的 **应用修改**

改动会先进入「待修改清单」，随时可以移除或清空，最后统一写入。这样比改一次写一次安全，也方便你反悔。

### 两个细节

- **支持「设为」和「增加」两种模式** —— 想直接改成 999999 就用「设为」，想加 5000 就用「增加」。
- **自动同步「同一时刻」的存档** —— 你停下游戏时手动存的那一档，和自动存档往往停在完全相同的状态。如果只改一个，从另一个读档就会发现数值变回去了。工具默认会把同一时刻的所有存档一起改掉，写入前会列出来让你确认。

## 安全机制

改存档最怕的是「改坏了读不了档」或者「改错文件把别的游戏也搞了」。这个工具内置了四道闸：

| 闸 | 作用 |
|---|---|
| **写前必备份** | 每次应用修改前，把涉及的存档复制到 `game/saves/_ag17_backups/时间戳/`。界面上有「还原备份」一键回退。 |
| **变量重合度校验** | 写入前先读目标存档的变量集，和源存档比对。重合度低于 60% 直接拒绝写入 —— 从根上防止改错游戏。 |
| **写后验签** | Ren'Py 8.4+ 会给存档做 ECDSA 签名，改过就失效、游戏会拒绝加载。工具用本机私钥自动重新签名并立即验签。 |
| **写后读回核对** | 写完重新读取一遍，逐项确认改动真的生效了，没生效就在日志里标红。 |
| **地盘校验** | 拒绝写入任何不在当前游戏目录下的文件。 |

另外，**镜像目录按「游戏名前缀」匹配，绝不按文件名匹配**。Ren'Py 会把存档同时写到游戏目录和 `%APPDATA%\RenPy\<存档目录>\` 两处，所有 Ren'Py 游戏都用 `auto-1-LT1.save` 这种固定文件名 —— 按文件名匹配会把别人电脑上其他游戏的存档一起覆盖掉。

## 工作原理

Ren'Py 的 `.save` 文件其实是个 zip 包：

```
xxx-LT1.save  (zip)
├── log             # 核心：pickle 协议 5 的 tuple (store_dict, ...)
├── json            # 元数据 _save_name / _ctime / _version
├── screenshot.png
├── extra_info
├── renpy_version
└── signatures      # ECDSA 签名（Ren'Py 8.4+）
```

`log` 里那个 store 字典就是所有游戏变量，键形如 `store.g_gold`。

### 三个技术要点

**1. 字节级 patch，绝不重新序列化。**
`log` 里含大量游戏自定义类，直接 unpickle → 改 → 重新 pickle 会把它们全部弄坏。正确做法是在 pickle 字节流里**精确替换那一个值的编码**，其余一个字节都不动。替换后还要修正所属 `FRAME` 的长度字段。

**2. 键名会被压缩成 memo 引用。**
`'pKey'` 第一次出现是 `SHORT_BINUNICODE 'pKey'`，**第二次起就变成 `BINGET 29`**。所以定位时必须自己维护一张 memo 表，把 `BINGET` 解析回它引用的真实值。

**3. 容器元素有两种存法，判据不能只看一种。**
背包元素可能是**内联**写在容器区域里的，角色数据则可能是**提前生成、只放 memo 引用**的。只按「有没有内联」判断会误判（实测某个存档的角色表会从 97 项掉到 2 项）。正确做法是两条路都算、选命中条数多的那条。

### 读取

pickle 里含游戏自定义类，普通反序列化会失败。工具用一个「万能占位类」重载 `Unpickler.find_class`，把未知类都还原成普通属性字典，这样就能读全部内容了。

## 常见问题

**Q：改了没生效？**
A：进游戏读档看一下。如果是从手动存档读的，确认「同时改同一时刻的存档」那个勾是打开的。

**Q：游戏提示存档损坏 / 拒绝加载？**
A：多半是签名问题。确认改之前**至少运行过一次游戏**（这样 `%APPDATA%\RenPy\tokens\security_keys.txt` 里的签名私钥才存在）。工具启动时会在日志区提示有没有读到私钥。

**Q：找不到游戏？**
A：点右上角「手动指定游戏」，选到 `Agent17.exe` 所在的目录（里面有 `game` 文件夹的那一层）。

**Q：能改别的游戏吗？**
A：不能，这个是 Agent17 专用。不同引擎的存档格式、加密、校验方式完全不同，方法不可复用。同样是 Ren'Py 的游戏，变量名也完全不同。

**Q：改坏了怎么恢复？**
A：点「还原备份」，会自动列出备份目录，选最新的一个还原。备份在 `game/saves/_ag17_backups/` 下。

**Q：存档列表里怎么那么多 auto-xx？**
A：那是自动存档。可以用右上角的筛选框切到「仅手动」。
